# Setup

```console
$ git clone git@github.com:genlayerlabs/github-actions.git
$ cd github-actions
$ nix develop
```

`nix develop` installs the git hooks into `.git/hooks/`. They format Nix and
YAML and validate commit messages.

Run the checks the way CI does:

```console
$ nix flake check
```

Format everything:

```console
$ nix fmt
```

`.pre-commit-config.yaml` is generated by Nix and gitignored — do not edit it.
